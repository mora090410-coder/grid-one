Fundraiser workflow

Fill → Reconcile → Draw → Preview → Go Live

  • Fill: assign sold squares and keep private seller/payment notes.
  • Reconcile: check OPEN squares, duplicate labels, and advisory follow-up.
  • Draw: preview and commit axis digits before publication.
  • Preview: inspect the exact viewer link before sharing.
  • Go Live: publish one board link for game-day score and winner tracking.

Trust and recovery

The board stays useful when game-day data is imperfect.

  • Score authority and freshness stay visible.
  • Manual recovery can preserve a trustworthy board when automatic score data fails.
  • Public viewer data excludes private seller, contact, and off-platform payment metadata.
  • Winner resolution is recorded without implying GridOne handles money.
